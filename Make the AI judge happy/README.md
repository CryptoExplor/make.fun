# Make the AI judge happy (`ai-happy-01`)

An entry for the make.fun bounty **"Make the AI judge happy"** (`ai-happy-01`).

## Description
This program outputs a heartwarming, joyful image crafted to lift the AI judge's mood with real warmth, delight, and happiness.

## Output
The entrypoint writes the happy image directly to `/output/entry.png`:
- Format: JPEG / PNG
- Dimensions: 1024x1024
- Limits: Under 1 MiB
